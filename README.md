Структура файлов товародвижения (.../invent_trans/invent_trans_YYYY_MM.csv, формат CSV, разделитель ';')
    - item_id, идентификатор товара
    - location_id, идентификатор подразделения
    - trans_date, дата YYYY-MM-DD
    - qty, количество (разделитель целой и дробной части '.')
    - cost_amount, себестоимость (разделитель целой и дробной части '.')
> отрицательные значения qty - расходная операция, положительные - приходная операция

Структура файлов товарных остатков (.../stock/stock_YYYY_MM_DD.csv, формат CSV, разделитель ';')
    - item_id, идентификатор товара
    - location_id, идентификатор подразделения
    - trans_date, дата YYYY-MM-DD
    - qty, количество исходящего (на конец дня) остатка (разделитель целой и дробной части '.') на дату trans_date
    - cost_amount, себестоимость исходящего (на конец дня) остатка (разделитель целой и дробной части '.') на дату trans_date
